# star-runes-stats

Public stats page for the Slay the Spire 2 mod **Star Runes (별의 룬)**: https://adll1151.github.io/star-runes-stats/

The page has the same sections as the mod's private dashboard. It reads one JSON from the Supabase Edge Function
`public-stats`, which returns aggregates only: no install IDs, no feedback text, no Steam comment text, no dev-build runs.
`hero.jpg` is the mod's own preview art. d3 7.9.0 comes from jsDelivr, pinned with SRI. The page has no trackers.
